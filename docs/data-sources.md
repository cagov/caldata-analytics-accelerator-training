
You can [connect Power BI](https://learn.microsoft.com/en-us/power-bi/connect-data/) to many types of data sources, such as Excel files, databases, and the web. See Microsoft Learn for a full list of [Connectors in Power Query](https://learn.microsoft.com/en-us/power-query/connectors/) and which ones work with Power BI. The following resources provide guidance for connecting Power BI to selected data sources:

- **Excel file in OneDrive or SharePoint** - [From the Web connector using a file URL](https://learn.microsoft.com/en-us/power-query/sharepoint-onedrive-files#from-the-web-connector-using-a-file-url) (Microsoft Learn)
- **Microsoft Form responses** - [This Simple Trick Turns Microsoft Forms into Stunning Power BI Dashboards](https://www.youtube.com/watch?v=8JO9-1N5QTE&t=67s) (Pragmatic Works)
- **SharePoint list** - [Create a report on a SharePoint List in Power BI Desktop](https://learn.microsoft.com/en-us/power-bi/connect-data/desktop-sharepoint-online-list) (Microsoft Learn)
- **Power BI dataset (semantic model)** - [New Power BI Reports from a Golden Dataset](https://exceleratorbi.com.au/new-power-bi-reports-golden-dataset/) (Excelerator BI)
